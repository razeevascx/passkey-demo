## Project Overview

PasskeyDemo showcases the implementation of modern passwordless authentication using WebAuthn API and passkeys. This interactive demonstration helps developers understand how to integrate secure, user-friendly authentication without traditional passwords. Built with Next.js 15, it provides both educational content and practical code examples for implementing passkey authentication in web applications.

## Setup

1. **Clone the Repository**

   ```bash
   git clone https://github.com/razeevascx/passkey-demo.git
   ```

2. **Navigate to Project**

   ```bash
   cd passkey-demo
   ```

3. **Install Dependencies**

   ```bash
   pnpm install
   ```

4. **Start Development Server**

   ```bash
   pnpm dev
   ```

5. **Verify Installation**
   - Open browser: http://localhost:3000
   - Navigate to `/passkey` to test passkey functionality
   - Check `/mdx` for documentation examples
